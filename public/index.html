Agent integration profile
Adding another agent
  1. Register its identity and owner
    Define the actions and resources it can request.
  2. Attach a versioned policy pack
    Set resource allowlists, limits, approval roles and required evidence.
  3. Implement an execution adapter
    Normalise its action parameters and route execution through the gateway.
  4. Map controls to framework outcomes
    Reuse mappings and preserve evidence with each decision.
This build has two mock adapters. Real deployments need authenticated actors, protected credentials and integrations that cannot bypass the gateway.
